# Godot Corso 2026

Materiale del corso di sviluppo giochi con **Godot 4**.

Ogni cartella contiene il progetto Godot completo della lezione + la documentazione da studiare a casa.

---

## Lezioni

| Lezione | Argomenti |
|---|---|
| [Lezione 00](lezione-00/README.md) | Setup del progetto e degli asset |
| [Lezione 01](lezione-01/README.md) | Scena principale, Player, TileMap, movimento |
| [Lezione 02](lezione-02/README.md) | Camera2D, piattaforme mobili, organizzazione script |
| [Lezione 03](lezione-03/README.md) | Nemici, monete, killzone, Area2D, Physics Layers |

---

## Come usare il materiale

1. Vai nella cartella della lezione che ti interessa
2. Leggi il `README.md` della lezione
3. Scarica il progetto e aprilo con Godot 4

> Puoi scaricare l'intera repo come ZIP dal bottone **Code → Download ZIP** in alto a destra.
